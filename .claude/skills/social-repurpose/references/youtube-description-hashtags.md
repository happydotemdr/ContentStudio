# YouTube description & hashtags — sized for a Short

Source: `docs/headless-youtube-audit.md` §7 (Packaging) and §8 (Algorithm & distribution,
the AEO subsection). **Read the sizing warning first** — this is the part of the corpus
most likely to be misapplied to a Short.

## The sizing warning: don't apply the long-form AEO package to a Short

The corpus's dense, specific AEO description guidance — 500+ word structured
descriptions naming every brand/full name/location/concept, chapter markers as citable
mini-articles — is **long-form-cited**: "over 94% of AI-cited videos were long-form
(10–20 min band ~a third)" **[C]** (Romayroh, -j1ry1TCJU4). Shorts have no chapter
markers at all, and the corpus's own Shorts-specific guidance is explicitly lighter.

**For a standalone Short, write:**

- **[C] A short SEO description** and **1–6 niche hashtags** — this is the corpus's
  actual Shorts/small-channel-video guidance, not the full AEO package (Dan the
  creator, u_oNzUfC3lg; Make Money Matt, 10yFPNpnjY0). SEO minutiae (tags, hashtags,
  file names, descriptions) carry near-zero payoff for ranking beyond this on their
  own — YouTube's Gemini reads the video itself, so packaging is what matters more
  (Nate Black, J8LrrCpDNJI). Add the video to a relevant playlist too, for an extra
  surfacing location (Make Money Matt, 10yFPNpnjY0).
- **[C] Don't stuff irrelevant trending hashtags** — off-topic tags bring the wrong
  audience and damage co-visitation signal (Romayroh, T4b3pU6ApPM).

**`[I]`** **Apply the full 500+ word AEO description only if this Short has a long-form
companion piece** it's promoting or excerpted from — in that case, write the dense
AEO description *for the long-form video*, and keep the Short's own description light
per the rule above. Flag this explicitly in the output package (e.g. "note: full AEO
description applies to the long-form companion, not this Short — see below") so the
distinction isn't silently lost. This sizing split is this skill's own derivation from
the adjacent `[C]`-cited 94%-long-form finding, not a corpus-stated rule.

## AEO substance (apply within whichever description gets the fuller treatment)

- **[C] Pack the description with citable specifics** — full names, dates, places,
  numbers ("47,000 employees... in Q3 of 2026") — because AI assistants scrape
  transcripts/descriptions to cite videos, and AI reportedly cites YouTube as its #1
  source; ~half of cited videos had under 1,000 views when picked (Romayroh,
  G9LfE3k-IEI; Romayroh, mPHdSkvoN10; Romayroh, nFT1xNDprIk; One Person Business,
  oJHSWmZcsgE). — **strongly-supported**
- **[C] Chapter markers are citable mini-articles** — 78% of multiply-cited videos had
  chapters (Romayroh, -j1ry1TCJU4; One Person Business, 84bavOadYCI). **N/A for a pure
  Short** (no chapter support); relevant only for the long-form companion case above.
- **[C] Upload your own corrected transcript rather than relying on auto-captions** —
  auto-captions mangle the proper nouns AI needs for citation (Romayroh, -j1ry1TCJU4).
- **[C] Answer the core question in the first 30–60 seconds of the script/description**
  — AI overviews weight the intro most heavily (Romayroh, mPHdSkvoN10). This is a
  scripting note as much as a description note; if the Short's script already front-loads
  its payoff (per `shorts-scripting`), the description should restate that same payoff
  in its opening line, not bury it.
- **[C] "Good abandonment" is not a failure signal** — a viewer who got the answer and
  left early still counts as a satisfied view (Romayroh, t2y9pxGggdQ). Don't write
  description/CTA copy that reads as anxious about early drop-off; a clean, confident
  answer-first description is consistent with this finding.

## The preserved disagreement: SEO-dead vs AEO-critical

The corpus does not resolve this — state it rather than picking a side silently:

- **[C]** Nate Black: tags, hashtags, file names, and descriptions matter "far less"
  because YouTube's Gemini understands the video directly from its content — packaging
  (title/thumbnail) is what matters (Nate Black, J8LrrCpDNJI).
- **[C]** Romayroh: descriptions are AEO-critical for AI-citation discovery, and
  cited videos average 500+ description words (Romayroh, -j1ry1TCJU4).

**`[I]` Reconciliation used by this skill** (this skill's own synthesis, not a corpus
finding — the corpus leaves Nate Black and Romayroh in stated disagreement): these
aren't actually contradictory once you separate the audiences — SEO-for-human-search
is largely dead (Gemini doesn't need keyword-stuffed descriptions to understand the
video), but AEO-for-AI-citation is a live, separate channel that specifically rewards
dense, factual descriptions on long-form content. That's why the sizing rule above
splits Short (light) from long-form companion (dense) rather than applying one
description strategy to both.

## Pinned comment (posted alongside the upload)

**[C]** Reply to early comments with an open-ended question, and pin a comment linking
your money video — engineered early engagement in the first 1–2 hours after upload
matters, not just raw volume (Make Money Matt, RsAKa_WN1sU; Dan the creator, To5Dyc7AbkI;
Dan the creator, v562jH_TESg).

For a Short's post-copy package, write a **pinned comment suggestion** alongside the
description/hashtags:
- An open-ended question tied to the Short's hook/angle, to seed replies (e.g. "What
  would you have done in Jack Phillips's place?" for the worked-example Titanic angle).
- If this Short has a related money/pillar video already in the channel (see the
  long-form-companion case above, or an existing pillar video per the community-tab
  note below), link it in the same pinned comment, per the corpus's "linking your money
  video" framing (Make Money Matt, RsAKa_WN1sU). If no such video exists yet, include
  the question only — don't invent a link target.

## Distribution note: the community tab

**[C]** Community posts now surface directly into the Shorts feed and can outperform
livestreams (vidIQ, rBIeT9iLmnU). If the user wants a companion community post
alongside the YouTube description package, this is a legitimate corpus-grounded
addition — write it in the same short, citable-specifics style as the Short's own
description, not as a separate invented format.
